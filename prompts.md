# CampusSphere // Significant Prompts & Evolution Log

This document records the chronological sequence of significant user prompts that guided the design, architecture, implementation, and documentation of the **CampusSphere** project (formerly Campus Twin) for **ITER Campus, Siksha 'O' Anusandhan (SOA) University, Bhubaneswar, Odisha**.

---

## Chronological Prompts Log

### Prompt 01: Project Initiation & Vision
> **Prompt:**  
> *"So my project name is Campus twin and I am ready to do all the work"*

* **Context & Objective:** Kickstarted the hackathon initiative to build a modern smart campus digital twin and utility operations system for university students.

---

### Prompt 02: Core 3-Column Executive Cockpit Dashboard
> **Prompt:**  
> *"Create a modern, high-density, single-page executive web application dashboard for a Hackathon project: 'CampusSphere // Unified Student Utilities & Hyperlocal Campus Navigation'.*  
> *1. Structural Layout Blueprint (Strict 3-Column Cockpit Layout)*  
> *- Top Header Bar: App Name 'CampusSphere' with an academic/shield vector badge, pill-shaped segmented navigation tabs with smooth active states ([Overview] | [Wayfinder & Maps] | [Utility Hub] | [Resource Analytics]), Quick Notification bell, Quick Search icon, User Profile avatar chip.*  
> *- Left Sidebar Column: Live Alerts & Notices (Central RO Plant filter maintenance, Academic Library Xerox queue surge, IoT Lab 304 open access), Compact 3-Pill quick metrics bar, Campus utility radial status gauge (68% load).*  
> *- Center Main Hero Column: Hyperlocal wayfinder, Route title 'ITER Gate 1 -> Block B (CSE Wing)', Interactive transit hub with Transit Line 02 shuttle countdown clock (04:15 MIN), Next Destination badge.*  
> *- Right Sidebar Column: Automated print queue dispatcher, Live building headcount (1,420 entries), AI crowd surge forecast."*

* **Context & Objective:** Established the core 3-column cockpit layout, high-density information architecture, and the foundational aesthetic of CampusSphere.
